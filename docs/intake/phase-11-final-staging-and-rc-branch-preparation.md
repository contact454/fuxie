## CTO Decision For `apps/web/public/sw.js`

Recommended decision: stage `apps/web/public/sw.js` only if the CTO accepts generated service worker artifacts as tracked release artifacts for this repo.

Decision options:

| Option | When to choose | Command path | Risk |
| --- | --- | --- | --- |
| Stage generated artifact | Repo policy expects generated `public/sw.js` in commits | Stage after a clean `pnpm build` | Keeps build output visible but can add churn |
| Regenerate then stage | CTO wants a fresh artifact immediately before RC | Run `pnpm build`, inspect diff, then stage | Requires gate awareness because build may touch artifact |
| Restore and exclude | Repo policy should not commit generated service worker output | Restore only with explicit approval | Avoids generated churn but must not break deployment expectations |

Phase 11 recommendation: do not decide silently. Keep G4 pending until CTO/user approval.
