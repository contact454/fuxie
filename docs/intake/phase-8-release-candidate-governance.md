## Generated Service Worker Policy

Evidence:

- `apps/web/next.config.ts` uses `@serwist/next`.
- Serwist build output says it bundles the service worker at `/sw.js`.
- `apps/web/public/sw.js` changed by production build and remains a 1-line generated minified artifact.

Policy:

- Do not manually edit `apps/web/public/sw.js`.
- For an RC, keep `apps/web/public/sw.js` only if it was produced by the same clean `pnpm build` used for the release gate.
- If the team decides generated service worker output should not be committed, restore it by explicit CTO decision before staging.

Current Phase 8 decision: keep the current `sw.js` as the clean-build generated artifact for RC candidate evidence.
