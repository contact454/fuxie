# Fuxie German Village Concept

## Summary

Fuxie German Village turns the current learning app into a cozy German-learning world. Learners return each day to a familiar village, complete small study missions, earn XP and Fucoin, collect language items, and gradually unlock places that represent real learning progress.

This concept is inspired by cozy daily-life game loops, but it must stay original to Fuxie: Fuxie Bright Sky colors, Fuxie mascot as the central coach, German learning clarity, and no direct copying of external game IP.

## Core Metaphor

| Current Fuxie surface | Village metaphor | Learning purpose |
| --- | --- | --- |
| Dashboard | Village Square | Daily return ritual, next best action, mission overview |
| Mission Board | Village Notice Board | Daily/monthly/quarterly goals |
| Fucoin | Village reward coin | Spendable motivation layer |
| Rewards Shop | Fuxie Market | Reward browsing and future redeem flow |
| Inventory | Learner backpack / trophy room | Owned rewards, receipts, collectibles |
| Vocabulary | Collection Book | Words become collectible cards and themed sets |
| Listening | Radio Booth | Audio practice as village broadcasts |
| Reading | Library | Text practice as books and notice letters |
| Writing | Post Office | Writing practice as letters/forms |
| Exam | Town Hall Challenge | Formal readiness and milestone tests |
| Streak Freeze | Safety charm | Protects learning habit without shame |

## Design Principles

- **Cozy, not childish**: playful warmth for A1-B1 learners, but still credible for exam prep.
- **Game layer supports study**: mission, Fucoin, inventory, and visuals must explain why to learn next.
- **Fuxie remains the brand anchor**: generated assets expand the world around Fuxie, not replace the mascot.
- **Fuxie Bright Sky first**: sky blue and teal lead; amber is reserved for Fucoin/rewards; red is only for errors or critical states.
- **Mobile-first village**: each screen must work as a fast daily check-in on phone.
- **Progress must feel owned**: collections, inventory, village locations, and unlocked visuals make learning visible.
- **No pressure loops**: Streak Freeze and coach copy should protect motivation, not punish absence.
- **Original IP only**: avoid copying names, characters, UI, item shapes, or layouts from any specific game.

```text
Lighting/mood: bright morning sky, cheerful, calm, low-pressure learning energy

```

- Themes become collections.
- Words become collectible cards.

- The CEFR badge asset begins to connect Dashboard, RewardPreview, and Course into one collectible language.

## Review Checklist

- Brand: clearly Fuxie Bright Sky, not generic cozy game.
- IP safety: no direct Animal Crossing/Nintendo copying.
- Learning clarity: next action remains obvious.
- Visual motivation: Fucoin/reward/item ownership feels tangible.
- Mobile ergonomics: no tiny unreadable UI.
- Cognitive load: game layer does not obscure study task.
- Mascot role: Fuxie guides, rewards, or supports; not decorative clutter.
- Production feasibility: generated assets can be cropped into real UI cards.
