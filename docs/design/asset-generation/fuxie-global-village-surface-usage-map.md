## Design Guardrails

- Use scene direction boards for alignment and mockups only.
- Use alpha drafts as starting points, not final runtime art.
- Do not place decorative props unless they clarify CTA, progress, reward, feedback, empty, or error state.
- Teacher/admin surfaces should use the village layer lightly: one anchor visual per surface plus restrained frames.
- Learner surfaces can use stronger village identity, especially reward loops and skill entry points.
