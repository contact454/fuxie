## 6. Final decision

**READY TO TAG DONE — for the rollout infrastructure.**

The infrastructure scope shipped by this spec is complete and verifiable:

- All 13 P0 surfaces declare `default | empty | error` (and `locked` where gating exists) via `state-shell` (AC1 🟢).
- All 23 correctness properties have authored test files; the `pnpm check:quick` gate runs them on every PR (AC2 🟡 / AC3 🟢).
- The Visual QA runbook has been executed for every P0 surface and committed as 13 checklist files (AC4 🟢).
- Performance and accessibility integration tests exist for every P0 surface (AC5 🟢).

No AC is 🔴 RED. The single AMBER (AC2) is bounded to optional starred sub-tasks per the spec's own convention and does not block Done.

**Out of scope for this Done tag** (separate scoped initiatives owned by PM, sibling specs partially landed 2026-05-16):

1. **Pre-existing codebase cleanup — partial** (Risk R1, now 🟡 PARTIAL). Asset paths: 5/96 resolved by `asset-registry-cleanup` (Phase 2); 91 pre-existing tracked debt remain (`fuxie-live-qa/page.tsx`, `fuxie-live-3d.tsx` rig config, auth/landing pages, course-node test fixture). Untranslated strings: 5/419 resolved by `learner-copy-localization-backfill` (`writing-player.tsx` namespace `WritingPlayer`); 414 remain. CI gate continues to surface regressions on touched files. Bulk migration of the remainders is a separate sprint commitment.
2. **Asset audit coverage push to ≥95% — partial** (Risk R2, now 🟡 PARTIAL — best-effort). Coverage improved 23.08% → 49.02% by `asset-registry-cleanup` Phase 3 (26 wires + 2 deletes + 2 archive reason updates); forbidden refs 8 → 0 (FOUNDATION extracted to `scripts/`); orphans = 0; preference issues = 0. Long-tail rollback variants (`.png` siblings, v1 world variants) intentionally kept-archived per Option 1 PM decision; reaching ≥95% requires DSD-authorized rollback-path deletion in a follow-up milestone.

These two items are tracked, owned, and scheduled — they are not silent risks. The CI gate, asset audit script, and state-shell coverage script will surface regressions automatically as work proceeds.

**Tag Done condition met.** Per Req 20.6: no AC is red, every open item has a named owner, and every risk has a documented mitigation.
